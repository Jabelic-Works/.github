## What We Do

`jabelic-works` is where Jabelic builds and maintains products, experiments, and tools as an independent developer.

- Build web applications, internal tools, and product prototypes end to end
- Explore frontend architecture and maintainable UI systems
- Create practical automation, tooling, and supporting backend services
- Share reusable code, workflows, and technical ideas in public

<br />

## Focus Areas

- Product Engineering
- Frontend Architecture
- Developer Experience
- Automation & AI Workflows

## Philosophy

The goal is to create software that stays clear, useful, and maintainable over time.

- Build with intention, not excess
- Favor clarity over cleverness
- Keep the stack modern, but keep the solution practical
- Use technology to solve real problems without unnecessary complexity
